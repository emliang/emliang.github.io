A power-grid operator must choose how much power each generator should produce to meet demand. A neural network trained on past solutions can suggest a dispatch quickly, but even a small error can violate a generator limit. Homeomorphism methods represent the feasible region in simpler coordinates, where valid decisions are easier to construct—in the 2D diagrams below, think of each point in KKK as a valid two-generator dispatch.

Follow the copper point: what stays the same as it moves from the disk to the target region?

The same coordinate map supports three tasks: recovering an infeasible prediction, optimizing a decision, and learning a distribution of feasible samples.

A feasible set, in different coordinates

Let KKK contain the admissible decisions, and let BBB be the unit ball: all coordinates with length at most one. In our 2D figures, BBB is a filled disk. Following optimization notation, xxx denotes the decision itself (rather than a predictor's input features), and zzz is its reference coordinate. A homeomorphism Φ\PhiΦ pairs each zzz in BBB with exactly one xxx in KKK, and its inverse Φ−1\Phi^{-1}Φ−1 takes xxx back to zzz. Both directions are continuous: small changes remain small in either coordinate system. The map can still stretch or compress distances.

With Φ(B)=K\Phi(B)=KΦ(B)=K, any coordinate zzz in the ball decodes to a feasible decision. Constraint handling shifts to keeping coordinates inside the ball, where projection is a simple calculation.

The inverse map brings existing decisions and training data into reference coordinates. A homeomorphism preserves topology even when it changes the region’s shape.

Roadmap · One representation, three operations

Learning
Recover an infeasible prediction by searching along a ray in reference coordinates, checking each probe against the original constraints.
Optimization
Take gradient steps in reference coordinates, project cheaply onto the ball, then map each iterate back to a feasible decision.
Sampling
Learn and sample the data distribution inside the ball with a reflected flow, then decode into feasible decisions.

Constructing the map: follow a ray

For a compact convex set with nonempty interior, a gauge map uses rays from an interior point x0x_0x0​. Each ray reaches the boundary at a unique distance. Rescaling the corresponding ball radius by that distance gives the map.

Write z=ruz=ruz=ru, where uuu is a unit direction and 0≤r≤10\le r\le10≤r≤1. If R(u)R(u)R(u) is the distance from x0x_0x0​ to the boundary along uuu, the map is

Φ(ru)=x0+r R(u) u,Φ(0)=x0.\begin{aligned}\Phi(ru) &= x_0 + r\,R(u)\,u,\\\Phi(0) &= x_0.\end{aligned}Φ(ru)Φ(0)​=x0​+rR(u)u,=x0​.​

The map preserves the relative distance rrr along each ray: halfway to the ball boundary maps halfway to the target boundary, and a boundary point maps to the target boundary. The figures and explorer use x0=0x_0=0x0​=0.

Tabas and Zhang use gauge maps to turn bounded neural-network outputs into state-dependent safe actions for reinforcement learning,[1] and into feasible control sequences for model predictive control (MPC).[2] Their reference domain is an ℓ∞\ell_\inftyℓ∞​ unit ball—a box with each coordinate between −1 and 1—rather than the Euclidean ball illustrated here. Both constructions rescale rays from an interior point.

In the star-shaped example, each ray still reaches a single boundary point, varying continuously with direction. These properties let the radial construction work despite nonconvexity; arbitrary nonconvex regions need not have them.

The map’s cost lies in evaluating the boundary distance. Linear, quadratic, and conic constraints allow structured calculations; general convex constraints can use a one-dimensional search along each ray. The implementation provides these calculations.

Learning: recover a usable prediction

The explorer constructs a feasible decision from a coordinate. A predictor can use this decoder directly, or keep its existing output representation and use the map to recover an infeasible prediction.

Construct the output in feasible coordinates. With an exact map onto the feasible set, a network can predict zzz, enforce z∈Bz\in Bz∈B, and return Φ(z)\Phi(z)Φ(z). For input-dependent constraints, use the map for that input. Training through the decoder lets the model account for how its coordinates become decisions. A related feasible-output construction appears in RAYEN, an output layer that enforces supported convex constraints.[3]

Recover a prediction after it is made. Here the predictor outputs a decision, while a separate invertible network learns the coordinate map. Coupling-based networks are one established choice, with approximation properties studied by Teshima et al.[4] In Homeomorphic Projection, the network remains invertible outside the feasible region. It can therefore inverse-map an infeasible prediction, recover a feasible point in reference coordinates, and map it back.[5]

Choose a reference-space center whose mapped decision is known to be feasible, then bisect the segment from the prediction’s reference coordinate to that center. Map each midpoint back, test the original constraints, and retain a feasible endpoint as the interval narrows. Return that endpoint’s mapped decision. These checks remain necessary because an invertible learned map need not map its ball exactly onto the true feasible set.

This recovery need not return the Euclidean nearest feasible decision. If the map stretches a direction strongly, a small move in reference coordinates can become a large change in dispatch. Learning a map with small distortion helps keep that correction modest. The paper relates the loss to prediction error, map approximation, distortion, and bisection accuracy. On nonconvex AC optimal power flow benchmarks, this checked bisection achieves 100% solution feasibility with orders-of-magnitude lower inference latency than iterative optimization-based projection solvers.[5]

Optimization: improve the decision inside the ball

Prediction recovery repairs a given decision; optimization searches for a low-cost one. Minimizing f(x)f(x)f(x) over x∈Kx\in Kx∈K is equivalent, under an exact homeomorphism, to minimizing the composite objective h(z)=f(Φ(z))h(z)=f(\Phi(z))h(z)=f(Φ(z)) over z∈Bz\in Bz∈B. Every feasible decision has a coordinate, so the best objective value is preserved.

When projection onto KKK is expensive, Hom-PGD can replace it with ball projection, map evaluation, and differentiation. It takes a gradient step on the transformed objective, projects onto BBB, and maps the iterate back.[6] With step size η\etaη, the update is

zk+1=ΠB ⁣(zk−η ∇h(zk)),xk+1=Φ(zk+1).\begin{aligned}z_{k+1} &= \Pi_B\!\left(z_k - \eta\,\nabla h(z_k)\right),\\x_{k+1} &= \Phi(z_{k+1}).\end{aligned}zk+1​xk+1​​=ΠB​(zk​−η∇h(zk​)),=Φ(zk+1​).​

ΠB\Pi_BΠB​ is projection onto the unit ball: keep a point if its length is at most one; otherwise divide it by its length. The gradient ∇h\nabla h∇h is taken with respect to the reference coordinate zzz, so it accounts for how the map changes the decision. The method avoids projection onto the original set KKK; feasibility of each decoded iterate relies on the map and numerical operations.

A nonlinear map can turn even a convex objective into a nonconvex one. Under the paper’s regularity assumptions, Hom-PGD matches standard unaccelerated first-order convergence rates without solving an optimization oracle at each step, and follow-up work (Hom-PGD+) extends this reparameterized optimization to non-convex ball-homeomorphic sets.[7] Map distortion affects the constants and practical conditioning; the choice of interior center can also influence convergence speed.

Sampling: learn the distribution in simple coordinates

Optimization seeks one low-cost decision. Sampling aims to produce a collection of feasible dispatches with patterns and frequencies learned from data. The point clouds below show why a feasible map alone cannot meet that requirement.

Mapping points also moves probability mass

Where do points become crowded, and where do they spread out after the map?

Even uniform samples in the ball generally become nonuniform after mapping. A region that expands under Φ\PhiΦ receives the same probability mass spread over more area. A compressed region receives denser mass.

These clouds show geometric mapping without a trained generative model. For a smooth invertible map, local volume change determines the change in density—the principle behind normalizing flows.[8] To match a dataset of dispatches, the model must learn the corresponding distribution in ball coordinates.

Flow matching learns a velocity field that moves samples from a simple starting distribution toward the data distribution.[9] Reflected Flow Matching extends this idea to bounded domains.[10] Reflection adjusts motion at the boundary to keep samples inside.

Gauge Flow Matching learns the data distribution in reference coordinates.[11] Map feasible training data back to the ball with Φ−1\Phi^{-1}Φ−1, then train a velocity field on that transformed distribution. At inference, start from a prior supported inside BBB, use reflected flow sampling within BBB, and map the generated coordinates into KKK.

Which direction prepares the training data, and which direction produces new decisions?

Gauge Flow Matching therefore uses a reflected sampler within BBB. An unconstrained numerical flow can leave the ball, and invertibility alone cannot prevent that. With an exact feasible map, ball-space feasibility carries over to the decoded samples; the learned flow determines how closely their distribution matches the data.

The map must fit the geometry

The choice of map depends on the feasible region’s topology and dimension, and on the cost of working in the new coordinates.

  • Topology. A disk can deform into a filled nonconvex shape with the same topology. It cannot map homeomorphically onto an annulus with a hole or a disconnected set. Such domains require a different reference space, multiple charts, or another method.
  • Dimension. Equality constraints can reduce the number of independent variables. Work in those reduced coordinates and reconstruct the dependent variables when a suitable parameterization exists. A full-dimensional ball cannot be treated as a homeomorphic representation of an arbitrary lower-dimensional feasible surface.
  • Distortion and computation. Continuity and invertibility establish a correspondence; bi-Lipschitz control additionally limits stretching and compression. These properties matter for correction quality, optimization conditioning, and distribution error. They must be weighed against map construction, evaluation, and any constraint checks. Here, bi-Lipschitz means that both the map and its inverse have bounded stretching.

For convex bodies, a gauge map offers a direct construction. For more general non-convex ball-homeomorphic sets, a learned or structured reparameterization—as in Homeomorphic Projection and Hom-PGD+—can still apply,[5][7] though invertibility alone establishes neither domain coverage nor constraint satisfaction.
